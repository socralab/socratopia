# Security

Please report security issues privately to **support@socratopia.app** with "Security" in the subject. Do not open a public issue.

Official Socratopia installers are always:

- macOS: signed with Developer ID Application: SOCRALAB LLC (U3L9MZ9HF9) and notarized by Apple;
- Windows: Authenticode-signed by SOCRALAB LLC.

Each release lists SHA-256 checksums in `SHA256SUMS.txt`. If you find a Socratopia installer with a different signer or checksum, do not run it, and please tell us where you found it.
